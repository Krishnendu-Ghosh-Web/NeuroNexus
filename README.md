# NeuroNexus Landing Page Form

## Overview

This repository contains a responsive landing page form built with HTML and CSS for NeuroNexus Innovations. The form collects user information including personal details, contact information, and professional data.

## Features

- **Form Fields**:
  - Full Name (text input)
  - Contact Number (phone input)
  - Address (multiline textarea)
  - Company Name (text input)
  - Email Address (email input)
  - Department (dropdown with HR, Sales, Development, Marketing, Others options)
  - Gender (radio buttons: Male, Female, Prefer not to say)
  - Submit button

- **Design Elements**:
  - Clean, modern UI
  - Responsive layout
  - Form validation indicators
  - Hover effects on submit button
  - Distinct form background with box-shadow
  - Focus states for form inputs

## Technologies Used

- HTML5
- CSS3

## Bonus Features Implemented

✅ Hover effect on Submit button  
✅ Different background color for the form  
✅ Box-shadow for minimalistic look  

## How to Use

1. Clone this repository
2. Open `index.html` in any web browser
3. Fill out the form fields
4. Click the Submit button
